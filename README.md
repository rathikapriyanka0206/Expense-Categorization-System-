# 💰 Expense Categorization System — Excel Dashboard

An interactive Excel dashboard that categorizes personal expenses (food, rent, travel, entertainment, utilities, shopping, health, education) and visualizes category-wise spending with pie/doughnut charts, KPIs and pivot tables — to improve understanding of **cash-flow management and expense control**.

## 📌 Problem Statement
Build a system that categorizes expenses like food, rent, travel and entertainment, and visualize category-wise spending using pie charts. The project improves understanding of cash flow management and expense control.

## 🎯 Objectives
- Create a dataset of **420 categorized transactions** (Oct 2025 – Sep 2026).
- Calculate key spending KPIs with formulas.
- Summarize the data with pivot tables.
- Present insights in a one-page, blue–red themed dashboard.

## 🗂️ Workbook Structure
| Sheet | Purpose |
|---|---|
| **Dataset** | 420 transactions: Txn ID, Date, Month, Category, Sub-Category, Description, Payment Mode, Expense Type (Need/Want), Amount (₹) |
| **KPI Workings** | Input assumptions and KPI formulas (SUMIFS, COUNTIFS, INDEX/MATCH, LARGE, RANK) |
| **Pivot Tables** | Category/Sub-Category, Month × Payment Mode, Category × Month summaries |
| **Dashboard** | KPI cards, charts, category table and key insights |

## 📊 Key KPIs

## 📈 Charts on the Dashboard
- **Category-wise Spending** — pie chart (share of total spend)
- **Monthly Spending Trend** — line chart
- **Needs vs Wants** — doughnut chart
- **Spend by Category (ranked)** — bar chart
- **Payment Mode Split** — doughnut chart
- **Top 8 Sub-Categories** — bar chart

## 🔍 Insights
1. **Rent** is the top spending category, followed by **Travel** and **Shopping**.
2. Spending peaked in **August 2026** and was lowest in **February 2026**.
3. Needs (51%) and Wants (49%) are almost balanced — there is room to cut discretionary spending.
4. **UPI** is the most used payment mode; ~93% of spend is digital.

## 🛠️ Excel Skills Used
Pivot tables • SUMIFS / COUNTIFS • INDEX-MATCH • LARGE / RANK • Conditional formatting & data bars • Pie, doughnut, bar and line charts • Dashboard design (blue–red theme)

## ▶️ How to Use
1. Download `excel/Expense_Categorization_Dashboard.xlsx`.
2. Open in Microsoft Excel (desktop recommended).
3. Go to the **Dashboard** sheet. To use your own data, edit the **Dataset** sheet and press **Data ▸ Refresh All**.
